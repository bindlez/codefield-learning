# Codefield 0.5.3-alpha

Practice automatically checks runnable published examples after editing in JavaScript, Ruby, and Python. The live panel shows example counts, inputs, returned values, expectations, and available trace steps. Rust, C++, C#, Java, and Crystal can automatically use their remote compiler after permission is given. Passing published examples is useful feedback and does not submit a solution or verify LeetCode's hidden tests.

The shared editor opens a method guide when a completion is highlighted. Python gains offline suggestions for common string, list, dictionary, and set methods. Notebook and lesson completion use the same runtime-aware completion interface as practice. The playground automatically previews local languages by default.

Python and Ruby traces include bounded previews of simple lists and dictionaries. Trace output remains partial, and unsupported examples and signatures may require custom test calls. The pop-out remains minimal.

Browser checks covered automatic five-example JavaScript and Python results, Ruby execution, Python autocomplete and method guidance, Code Model, mobile-sized layouts, and simulated voice input. Physical phones and microphones have not been tested. See `docs/next-pass.md` for remaining work.
