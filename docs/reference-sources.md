# Language reference sources

The offline Ruby index contains short descriptions and signatures extracted from the [Ruby 4.0 standard-library reference](https://docs.ruby-lang.org/en/4.0/). It covers the instance-method pages for String, Array, Hash, Set, Enumerable, Enumerator, Integer, Float, Numeric, Object, Kernel, Range, Regexp, Symbol, Time, File, IO, Class, and Module. Each method links to the official reference for full context and examples. Ruby and its documentation are distributed under the [Ruby license](https://www.ruby-lang.org/en/about/license.txt).

Python's built-in runtime docstrings are used when Pyodide is available, with a bundled set of common method summaries as a fallback. Links point to the [Python standard types reference](https://docs.python.org/3/library/stdtypes.html).

Other language links point to official language documentation where available. C++ links currently use cppreference. The offline index is not a complete inventory of every installed library or user-defined method. Generic fallback text identifies the method and provides a reference link rather than inventing its behavior.
