# Using Ruby Trail

Open **Ruby Trail** from the Playground. Start with **Learn Ruby**, select a lesson, read its explanation and predict the example's behavior. Edit the example and press **Run example**; printed output appears below the editor. Use **Explore a value** above the editor to try supported transformations. The Code Model offers a best-effort view of names and values.

The **Review challenge** asks you to predict and explain examples from the first path. Reveal the explanation after thinking it through. The **Documentation guide** demonstrates how to navigate Ruby's official reference, read signatures, find inherited methods and test edge cases. Its reference links open the official Ruby 4.0 documentation.

Mark complete records a self-reported milestone; it is not an automatically graded test. Completion and notebook text are saved in browser storage. Lesson edits are temporary and reset when changing lessons; copy work you want to keep into a saved file. Clearing browser data can erase notes and progress.

Ruby loads its runtime over the network on first use. Run trusted code only. The editor, trace and value explorer are learning aids and do not guarantee correctness. This introductory path is not a complete Ruby curriculum or proof of mastery. Continue with projects, tests, the official reference and code review.
