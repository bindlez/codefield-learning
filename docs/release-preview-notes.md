# Codefield 0.4.0 testing preview

This prerelease is for testing. Extract the ZIP and launch `Start Codefield.cmd` with Node.js 22 or newer installed.

Includes the shared editor, guided learning, problem catalog, basic voice workspace, topic navigation, timed practice, and limited live tracing. Automated suite: 79 tests passed. Browser checks exercised example runners and Ruby/Python tracing.

Known limits: Rust, C++, and C# do not have line-level practice tracing; the voice workspace is not a complete hands-free workflow; harder verified variants and comprehensive topic paths are not complete; mobile microphones and physical devices have not been verified. Some catalog entries require network access or the local server to retrieve statements. See `docs/testing-preview.md` and `docs/mobile-voice-delivery-backlog.md` for details.
