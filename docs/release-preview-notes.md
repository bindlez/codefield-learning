# Codefield 0.4.0 testing preview 2

This prerelease is for testing. Extract the ZIP and launch `Start Codefield.cmd` with Node.js 22 or newer installed.

Includes the shared editor, guided learning, problem catalog, basic voice workspace, topic navigation, timed practice, and limited live tracing. Two problems have checked harder variants, and practice and lesson editors offer additional language-specific method suggestions. Automated suite: 82 tests passed. Browser checks exercised example runners, Ruby/Python tracing, and the harder-variant flow.

Known limits: Rust, C++, and C# do not have line-level practice tracing; the voice workspace is not a complete hands-free workflow; only two harder variants are included and comprehensive topic paths are not complete; mobile microphones and physical devices have not been verified. Some catalog entries require network access or the local server to retrieve statements. See `docs/testing-preview.md` and `docs/mobile-voice-delivery-backlog.md` for details.
