# Codefield 0.5.1-alpha

This testing release improves the voice workspace for desktop and phone-sized screens. Microphone controls remain accessible while scrolling, recognition can reconnect after a normal pause, and interim speech appears while listening. Optional spoken feedback, confirmed replacement, and choosing among repeated identifier matches make corrections easier.

The voice editor requests a hidden software keyboard while listening and restores normal keyboard input when the microphone stops. Browser support varies. Recognition may rely on a network service and must be started by the user.

The automated suite passed 90 tests. Simulated speech and a 390-pixel browser layout were checked along with practice, learning, Code Model, and autocomplete flows. Physical phones, real speech recognition, screen readers, and mobile keyboards remain to be validated.

See `docs/next-pass.md` for the remaining semantic model, execution, practice, voice, and project work. This remains an alpha release.
