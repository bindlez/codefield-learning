Voice commands and examples

Complete voice coding guide

Build statements

Try “variable count equals 3”, “new line”, “if condition count greater than 2”, then “print expression count”. Also: “set count to count plus 1”, “while condition count less than 10”, “return expression count”, and “comment explain this loop”. Templates adapt to the selected language. Use existing program starters for compiled languages.

Write code

Say “insert hello” for literal text. Say “new line”, “tab”, “space”, “dot tally”, “open parenthesis”, “close parenthesis”, “open bracket”, “close bracket”, “open brace”, “close brace”, “comma”, “colon”, “semicolon”, “quote”, “single quote”, or “underscore”. Operators: “equals”, “equals equals”, “not equals”, “less than”, “greater than”, “less than or equal”, “greater than or equal”, “plus”, “minus”, “multiply”, “divide”, and “modulo”.

Explore and edit

Say “dot” or “suggest methods”, then “use suggestion 1”. Say “explain tally”, “highlight tally”, “highlight back three”, or “find tally”. If a name occurs more than once, say “choose first” or “choose 2”. Say “replace selection with text” or “delete selection”, followed by “confirm” or “cancel”. “Select all”, “undo”, and “redo” are also available.

Move and listen

Say “go to line 3”, “go to start”, “go to end”, “go to line start”, or “go to line end”. Say “read code”, “read line”, or “read output”. Enable Speak feedback to hear method suggestions and explanations.

Practice and files

Say “read problem”, “read example”, “next problem”, or “run code”. Say “save file demo”, “open file demo”, or “new file” (confirm to clear). Change languages with “language ruby”, “language python”, “language javascript”, “language rust”, “language c plus plus”, “language c sharp”, “language java”, or “language crystal”. Say “stop listening” to stop the microphone.

Commands are interpreted locally; speech recognition and its network requirements depend on your browser. Run code before reading fresh output. Compiled languages ask before sending code to a remote compiler.
